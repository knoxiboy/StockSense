# Contributing to StockSense

First off, thank you for considering contributing to StockSense. It's people like you that make StockSense such a great tool.

## Where do I go from here?

If you've noticed a bug or have a feature request, please make sure to check the [Issues](../../issues) to see if it has already been reported. If not, open a new issue describing the problem or the feature you'd like to see.

## Fork & create a branch

If this is something you think you can fix, then fork StockSense and create a branch with a descriptive name.

A good branch name would be (where issue #325 is the ticket you're working on):

```sh
git checkout -b 325-add-dark-mode
```

## Get the test suite running

Make sure to install the necessary dependencies for both the frontend and backend, and run the respective test suites to ensure everything is working correctly before you begin.

## Implement your fix or feature

At this point, you're ready to make your changes! Feel free to ask for help; everyone is a beginner at first.

## Make a Pull Request

When you're ready, open a Pull Request. Provide a detailed description of what you've done, referencing any relevant issues. The maintainers will review your code and may suggest some changes before merging it.

Thank you!
